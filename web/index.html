Connect Monarch so your apps on this Wizard can use it. Your Monarch password never reaches this app.

  1. 1Sign in to Monarch

    Monarch opens in a new tab. Sign in, approve the data notice, choose Read access and tap Allow. New to Monarch? Create a Monarch account first; a Monarch subscription and MCP access are required.

  2. 2Paste the address you land on

    After Allow the tab shows an error page. That's expected. Copy the whole address from that tab (it starts with http://127.0.0.1) and paste it here.

    Lost the address or got an expired-code message? Start over and sign in again; each code works once. To revoke access yourself, open Monarch Settings → MCP Connector.
